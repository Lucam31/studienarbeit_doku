    \subsection{Python}
    Python ist eine interpretierte, plattformunabhängige Programmiersprache mit dynamischer Typisierung und automatischer Speicherverwaltung. Sie unterstützt mehrere Programmieransätze (insbesondere prozedurale, objektorientierte und funktionale Ansätze) und weist eine klare und leicht lesbare Syntax auf. \\
    Neben einer umfangreichen Standardbibliothek steht eine große Auswahl an Drittanbieterbibliotheken zur Verfügung, wodurch sich Python für viele Anwendungsbereiche effizient einsetzen lässt.

    Die wichtigsten Eigenschaften und Vorteile zusammengefasst sind:
    \begin{itemize}
        \item \textbf{Lesbarkeit und Wartbarkeit}: Die einheitliche und kompakte Syntax erleichtert das Verstehen von Quellcode und fördert eine einheitliche Code-Struktur.
        \item \textbf{Portabilität}: Python-Programme sind in der Regel ohne große Anpassungen auf unterschiedlichen Betriebssystemen lauffähig.
        \item \textbf{Umfangreiche Standardbibliothek}: Viele grundlegende Aufgaben (Datei- und Netzwerkzugriff, Datenformate, Tests, Logging) werden bereits durch die Standardbibliothek abgedeckt.
        \item \textbf{Große Community und Tooling}: Durch die Beliebtheit von Python existiert ein umfangreiches Ökosystem an Tools und Bibliotheken, die die Entwicklung unterstützen.
        \item \textbf{Wenig Boilerplate-Code}: Python ermöglicht es, bereits mit wenigen Zeilen Code ein lauffähiges Programm zu erstellen, was Prototyping und schnelle Entwicklung fördert.
    \end{itemize}

    \subsection{TypeScript} %erweitern?
    TypeScript ist eine von Microsoft entwickelte kompilierte Programmiersprache, die auf JavaScript basiert, wodurch die Nutzung von JavaScript-Bibliotheken und -Frameworks ermöglicht wird. Auch funktionale, prozedurale und objektorientierte Programmierung sind möglich. Eines der größten Features, das durch TypeScript hinzugefügt wird, ist die statische Typisierung. Verwendung findet TypeScript wie auch JavaScript in der Entwicklung von Webanwendungen. TypeScript wird kompiliert und in JavaScript umgewandelt, wodurch es in allen Browsern ausgeführt werden kann.

    \subsection{Verwendete Bibliotheken und Frameworks}
    Für die Entwicklung der Software werden verschiedene Bibliotheken und Frameworks verwendet, um die geplanten Funktionalitäten umzusetzen und die Entwicklung zu erleichtern:
        \subsubsection{OpenCV} OpenCV ist eine Open-Source-Bibliothek, die eine Vielzahl von Funktionen für die Bildverarbeitung und -analyse bietet. Dadurch können Merkmale und Muster in Bildern erkannt und verarbeitet werden.
        \subsubsection{gpiozero} Diese Python-Bibliothek ermöglicht die einfache Steuerung von GPIO-Pins auf dem Raspberry Pi. Sie bietet eine benutzerfreundliche API, um Sensoren und Aktoren anzusteuern, was die Entwicklung von Hardware-Interaktionen erleichtert. Im Gegensatz zu der RPi.GPIO Bibliothek läuft gpiozero auch auf dem Raspberry Pi 5, da diese Bibliothek auf der libgpiod Bibliothek basiert, welche die GPIO-Schnittstelle des Raspberry Pi 5 unterstützt. RPi.GPIO hingegen ist nicht mit der neuen GPIO-Schnittstelle kompatibel und kann daher nicht auf dem Raspberry Pi 5 verwendet werden.
        \subsubsection{React} React ist eine JavaScript-Bibliothek zur Erstellung von Benutzeroberflächen, die von Facebook entwickelt wurde. Sie ermöglicht die Entwicklung von interaktiven und dynamischen Webanwendungen durch die Verwendung von Komponenten, die den aktuellen Zustand verwalten und effizient aktualisieren können.
        \subsubsection{PySide6} PySide6 ist eine Python-Bibliothek für die Anbindung an das Qt-Framework, das zur Entwicklung von plattformübergreifenden Anwendungen verwendet wird. Es bietet eine umfangreiche Sammlung von Widgets und Tools, um grafische Benutzeroberflächen zu erstellen, und ermöglicht die Integration von weiteren Funktionen wie beispielsweise Websockets.

    \subsection{Entwicklungsumgebung}
    Visual Studio Code ist eine kostenlose, plattformübergreifende Entwicklungsumgebung, die von Microsoft entwickelt wurde. Sie bietet eine Vielzahl von Funktionen, die die Entwicklung von Software erleichtern, darunter Syntaxhervorhebung, Codevervollständigung, Debugging-Tools und eine integrierte Terminal-Emulation. \\
    Außerdem unterstützt Visual Studio Code eine Vielzahl von Programmiersprachen und bietet eine umfangreiche Sammlung von Erweiterungen, die zusätzliche Funktionen und Integrationen bereitstellen. Durch die plattformübergreifende Verfügbarkeit kann die Entwicklungsumgebung sowohl auf einem Laptop als auch auf einem Raspberry Pi verwendet werden.

    \subsection{Websockets}
    Websockets sind ein Protokoll, das eine bidirektionale Kommunikation zwischen einem Client und einem Server über eine einzige TCP-Verbindung ermöglicht. Zwar verwendet es den HTTP-Handshake, wodurch es mit HTTP kompatibel ist, jedoch wechselt es nach dem Handshake zu einem binären Frame-basierten Protokoll.
    Im Gegensatz zu herkömmlichen HTTP-Verbindungen, die für jede Anfrage eine neue Verbindung öffnen, bleibt bei Websockets die Verbindung offen bis einer der Teilnehmer die Verbindung schließt, wodurch eine Echtzeit-Kommunikation möglich ist.
