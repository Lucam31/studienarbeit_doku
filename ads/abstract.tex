\renewcommand{\abstractname}{Zusammenfassung}
\begin{abstract}
    Die vorliegende Studienarbeit befasst sich mit der Entwicklung und dem Testen eines ferngesteuerten Modellfahrzeugs, welches zur Implementierung und Evaluation grundlegender Fahrassistenzfunktionen dient. Hintergrund der Arbeit ist die steigende Bedeutung von Assistenzsystemen in der Automobilindustrie und die damit verbundene Notwendigkeit, entsprechende Funktionen in einer kontrollierten Umgebung untersuchen zu können, bevor eine Übertragung auf reale Fahrzeuge erfolgt.

    Im Rahmen der Arbeit wird zunächst eine geeignete Hardwarearchitektur konzipiert, die auf einem Raspberry Pi als zentraler Steuereinheit basiert und durch Ultraschallsensoren, einen Hall-Sensor sowie ein Kameramodul ergänzt wird. Darauf aufbauend wird eine modulare Softwarearchitektur entworfen, die eine Kommunikation zwischen Fahrzeug und einer webbasierten Bedienoberfläche über WebSockets realisiert.

    Als Fahrassistenzfunktionen werden eine geschwindigkeitsabhängige Notbremsung mit Hilfe der Ultraschallsensorik sowie eine kamerabasierte Linienverfolgung mittels Bildverarbeitung und PID-Regelung implementiert. Außerdem wird eine manuelle Fernsteuerung über die Weboberfläche bereitgestellt.

    Die Funktionalität des Gesamtsystems wird anhand definierter Testfälle unter variierenden Bedingungen, darunter unterschiedliche Hindernisse und Lichtverhältnisse, evaluiert. Die Ergebnisse zeigen, dass die implementierten Systeme unter kontrollierten Bedingungen zuverlässig arbeiten, jedoch material- und umgebungsbedingte Einschränkungen aufweisen. Abschließend werden die Übertragbarkeit der Ergebnisse auf reale Fahrzeuge diskutiert sowie Verbesserungsansätze für zukünftige Weiterentwicklungen vorgeschlagen.
\end{abstract}


\renewcommand{\abstractname}{Abstract}
\begin{abstract}
    This student research project focuses on the development and testing of a remote-controlled model vehicle designed to implement and evaluate basic driver assistance functions. The background to this work is the growing importance of assistance systems in the automotive industry and the associated need to be able to investigate such functions in a controlled environment before transferring them to real vehicles.

    As part of the project, a suitable hardware architecture is first designed, based on a Raspberry Pi as the central control unit and supplemented by ultrasonic sensors, a Hall sensor and a camera module. Building on this, a modular software architecture is designed that enables communication between the vehicle and a web-based user interface via WebSockets.

    Speed-dependent emergency braking using ultrasonic sensors and camera-based line tracking via image processing and PID control are implemented as driver assistance functions. Manual remote control via the web interface is also provided.

    The functionality of the overall system is evaluated using defined test cases under varying conditions, including different obstacles and lighting conditions. The results show that the implemented systems operate reliably under controlled conditions, but show limitations due to material and environmental factors. Finally, the applicability of the results to real vehicles is discussed, and approaches for improvement are proposed for future developments.
\end{abstract}
